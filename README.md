## Overview
A lightweight, ad-free Android tip calculator built with a focus on flexibility and everyday usability.

Developed entirely in Java using Android Studio, the app features a fully programmatic UI with no XML layouts, allowing for precise control over layout and behavior. It was created as a hands-on way to strengthen Android development skills while building something practical, customizable, and easy to use.

**Setup:** To run this locally, open the project in Android Studio and run it on a device or emulator.

## Features
- **Rounding System**: Choose how the total after tip is rounded:
  - **Always Down**: Rounds down (floor)
  - **Always Up**: Rounds up (ceil)
  - **Dynamic**: Rounds up or down based on what is closer
  - **None**: No rounding applied
- **Bill Splitting**: Split the total evenly among up to 99 people
- **Tip Input Options**: Choose between a slider and quick buttons
- **Default Tip Percentage**: Set your preferred default tip
- **Numpad**: Choose between a standard or inverted numpad
- **Currency Support**: Includes a few popular currencies
- **Themes**: Multiple preset themes available
- **Ad-Free**: No ads at all
- **Offline**: Works completely offline, no internet needed
